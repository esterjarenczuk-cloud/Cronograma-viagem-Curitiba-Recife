## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação dos dados e tabelas.
- **CSS3**: Estilização responsiva e moderna.
- **JavaScript (ES6)**: Lógica do gráfico.
- **Chart.js**: Biblioteca externa para renderização do gráfico de rosca (doughnut chart).
